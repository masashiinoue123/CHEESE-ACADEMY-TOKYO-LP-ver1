# ①課題名

CHEESE ACADEMY TOKYO ランディングページ制作

---

## ②課題内容（どんな作品か）

チーズ職人養成学校「CHEESE ACADEMY TOKYO」をテーマにしたランディングページを制作しました。  
学校紹介、コース説明、ニュース、アクセス情報、お問い合わせフォームまでを1ページにまとめ、学校の魅力が伝わる構成を意識して作成しました。  
配色や余白、画像の見せ方を工夫し、親しみやすさと高級感のあるデザインを目指しました。

## ⑤工夫した点・こだわった点

今回の制作では、**チーズ職人養成学校の魅力が自然に伝わるデザイン**になるように工夫しました。

### デザイン面で工夫した点
- サイト全体の配色を**黄色・白・アイボリー系**で統一し、チーズを連想しやすい雰囲気にしました。
- 親しみやすさだけでなく、提出作品として見栄えがするように、やわらかく上品な印象を意識しました。
- ファーストビューでは、背景画像の上に暗めのオーバーレイを重ね、キャッチコピーが読みやすくなるように調整しました。

### レイアウト面で工夫した点
- セクションごとに単調にならないよう、**背景色・余白・カードデザイン**に変化をつけました。
- ABOUTでは4枚の画像を横並びに配置し、学校の雰囲気が視覚的に伝わるようにしました。
- COURSEでは、画像とテキストを左右交互に配置することで、同じ見え方の繰り返しにならないよう工夫しました。
- NEWSではカード型レイアウトを採用し、**画像 → 日付 → 見出し → 本文**の流れで情報が見やすくなるようにしました。

### 演出面で工夫した点
- 画像のホバー時に拡大する演出を入れ、視線が集まりやすいようにしました。
- NEWSカードには浮き上がる動きを加え、静的なページでも動きが感じられるようにしました。
- ボタンにはアニメーションを加え、操作できる要素だと分かりやすくしました。
- ナビゲーションから各セクションへスムーズに移動できるようにし、使いやすさにも配慮しました。

## ⑥難しかった点・次回トライしたいこと（又は機能）

今回の制作で難しかったのは、**画像・文字・余白のバランスを取りながら、全体を統一感のある見た目に仕上げること**でした。

### 難しかった点
- COURSEセクションでは、画像と文章を左右交互に配置しているため、文章量が異なっても全体の見た目が崩れないように調整するのが大変でした。
- 画像の大きさ、テキストエリアの幅、余白の取り方をそろえながら、3つのコースがひとまとまりに見えるように意識しました。
- NEWSカードでは、画像・日付・タイトル・本文の位置関係を整えながら、**読みやすさと見栄えの両立**を意識して調整しました。
- ホバー効果についても、派手になりすぎると落ち着きがなくなるため、自然に見えるように細かく調整しました。
- CONTACTフォームでは、項目名と入力欄の幅を整えて、全体がきれいに揃って見えるようにするのが難しかったです。

### 次回トライしたいこと
- JavaScriptを使った**スクロール連動アニメーション**
- お問い合わせフォームの**入力チェック機能**
- **スマートフォン対応のレスポンシブデザイン**
- デザイン性だけでなく、使いやすさや実用性も意識した実装

### 感想
今回の制作を通して、HTMLとCSSだけでも、**配色・余白・文字サイズ・装飾の工夫によってサイト全体の印象が大きく変わる**ことを実感しました。  
最初はレイアウトを整えるだけでも難しかったですが、少しずつ調整を重ねることで完成度が上がっていく過程がとても勉強になりました。  
今後は、見た目のデザインだけでなく、使いやすさや機能面も含めてより完成度の高いサイトを作れるようになりたいです。
